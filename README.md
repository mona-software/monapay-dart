# monapay

Dart/Flutter SDK for the MONA Pay API: create checkout links and VietQR codes, manage virtual accounts, webhooks and email notifications, and verify signed webhooks.

Requires Dart 3. No package dependencies: HTTP goes through `dart:io` `HttpClient`, and SHA-256/HMAC is implemented in pure Dart.

## Install

The package is not on pub.dev yet. Until it is, install it from GitHub:

```yaml
# pubspec.yaml
dependencies:
  monapay:
    git:
      url: https://github.com/mona-software/monapay-dart
```

Once it is published on pub.dev:

```yaml
# pubspec.yaml
dependencies:
  monapay: ^0.4.0
```

## Quick start

```dart
import 'package:monapay/monapay.dart';

Future<void> main() async {
  final client = MonaPayClient.fromEnv();
  final checkout = await client.checkouts.create({
    'amount': 250000,
    'order_code': 'DH10234',
    'return_url': 'https://shop.example/payment/return',
  });
  print(checkout['checkout_url']);
  client.close();
}
```

## Usage

### Client

```dart
// From environment variables (see Configuration)
final client = MonaPayClient.fromEnv();

// Or explicitly
final client = MonaPayClient(
  clientId: Platform.environment['MONAPAY_CLIENT_ID'],
  clientSecret: Platform.environment['MONAPAY_CLIENT_SECRET'],
  // optional: baseUrl, httpClient
);

final profile = await client.me();
```

- Client credentials (`clientId` + `clientSecret`) are the recommended login. `username`/`password` is a legacy fallback and does not work for accounts with 2FA enabled.
- The token is cached until 60 seconds before `expires_in`. A request that fails with HTTP 401 triggers a new login and is retried once.
- `X-Client-Secret` is sent on non-GET requests when a client secret is set.
- Methods return the `data` field of the response. Errors are thrown as `MonaPayException` with `status` and `body`.

### Hosted checkout

`checkouts.create` and `checkouts.cancel` send an `Idempotency-Key` header generated by the SDK; pass `idempotencyKey` to set your own. Fulfil orders from the `CHECKOUT_PAID` webhook or from `checkouts.get`, not from the browser redirect.

### Sandbox

```dart
await client.sandbox.createTransaction({
  'virtual_account_number': 'MONA123',
  'amount': 10000,
  'description': 'Sandbox test',
});
```

### Transactions

```dart
await for (final transaction in client.transactions.iterate(virtualAccountNumber: 'MONA123')) {
  print(transaction['transaction_code']);
}
```

`iterate` also accepts `sinceId`; the stream stops before the item whose `id` or `transaction_code` matches. It is not sent to the API.

### Webhooks

Verify the raw request bytes before parsing. `timestamp` and `signature` are the `X-Mona-Timestamp` and `X-Mona-Signature` header values.

```dart
final result = verifyWebhook(rawBytes, timestamp, signature, webhookSecret);
if (!result.ok) throw StateError('Invalid webhook: ${result.reason}');
```

The verifier uses HMAC-SHA256, compares in constant time, and accepts timestamps within `tolerance` seconds (default 300). Use `transaction_code` as the idempotency key.

### Flutter example

`example/qr_widget.dart` is a Flutter widget that calls `qr.generate` and displays the `qr_data_url` image returned by the API. It lives in its own package (`example/pubspec.yaml`), so the SDK itself keeps no dependencies.

## Configuration

`MonaPayClient.fromEnv()` reads (or takes an `environment` map):

| Variable | Purpose |
| --- | --- |
| `MONAPAY_CLIENT_ID`, `MONAPAY_CLIENT_SECRET` | API key credentials (recommended) |
| `MONAPAY_USERNAME`, `MONAPAY_PASSWORD` | Legacy password login; does not work for accounts with 2FA enabled |
| `MONAPAY_BASE_URL` | API base URL, defaults to `https://api.monapay.vn` |

Documentation: https://monapay.vn/docs
